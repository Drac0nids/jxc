# 极速云进销存 - Android App（Flutter）

> 对齐文档基线：`产品需求文档.md`、`架构设计文档.md`、`API接口定义文档.md`

## 1. 当前阶段

已完成 Android 端 **M1 启动骨架**：

- Flutter 工程基础配置（`pubspec.yaml`、lint、目录结构）
- 统一 API 客户端封装（`code/message/data/request_id`）
- 认证主流程（注册 / 登录 / 退出）
- 会话持久化（`shared_preferences`）
- 首页经营看板读取（`GET /reports/dashboard`）
- 库存与商品模块已接入统一手机扫码能力（`mobile_scanner` + 通用扫码弹层）：
  - 入库页：扫码快速累加 + 入库表单条码字段扫码回填
  - 出库页：扫码快速累加入库明细
  - 盘点页：扫码追加创建盘点明细
  - 商品页：条码筛选、创建/编辑条码字段扫码回填
  - 全部场景保留“手工输入 + 扫码枪回车”兼容路径

## 3. 环境变量

默认 API 地址：

```text
http://1.14.45.242:8080/api/v1
```

可通过 `--dart-define` 覆盖：

```bash
flutter run --dart-define=API_BASE_URL=http://1.14.45.242:8080/api/v1
```

## 5. 手机扫码能力覆盖说明（2026-03-09）

### 5.1 入库页

1. 在“扫码入库（快速累加）”点击 **手机摄像头扫码**：识别后自动累加数量 `+1`；
2. 在“入库表单 > 条码”点击 **手机摄像头扫码填入条码**：仅回填字段，不自动提交。

### 5.2 出库页

1. 在“扫码出库（快速累加）”点击 **手机摄像头扫码**；
2. 命中商品后自动新增/累加出库明细；可配合“销售单价（可选）”使用。

### 5.3 盘点页

1. 在“扫码选品（创建盘点单）”点击 **手机摄像头扫码**；
2. 命中后自动加入创建明细；重复商品会被去重拦截。

### 5.4 商品页

1. 在“商品列表”点击 **手机摄像头扫码筛选条码**：自动按条码筛选列表；
2. 在“创建商品 / 编辑商品”点击 **手机摄像头扫码填入条码**：自动回填对应条码字段。
