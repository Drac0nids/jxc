# 项目简介（Project Brief）

## 1. 项目定位
- **项目名称**：极速云进销存（Hyper JXC）
- **当前基线版本**：v1.1.0（文档已统一优化）
- **产品形态**：多租户 SaaS 进销存系统（Windows + Android 双端协同）

## 2. 项目目标
1. 提供中小商贸企业可落地的进销存闭环：商品、采购、销售、库存、报表。
2. 在并发场景下保证库存与成本一致性。
3. 支撑移动端扫码与弱网离线作业。
4. 保证租户隔离、权限可控、操作可追溯。

## 3. 已确定的范围
- 认证与租户体系（JWT + Refresh Token + RBAC）。
- 商品中心（条码唯一、价格体系、库存预警）。
- 采购入库（移动加权平均成本）。
- 销售出库（防超卖、库存校验）。
- 库存盘点与库存流水审计。
- 报表看板（经营概况、销售统计、利润分析）。

## 4. 全局约束（跨文档统一）
- 统一响应结构：`code / message / data / request_id`
- 库存字段统一：`current_stock`
- 成本语义统一：`unit_cost`（入库入参）/ `cost_price`（当前成本）
- 写接口统一幂等：`X-Idempotency-Key`
- 金额传输统一字符串，服务端映射 `rust_decimal`
